Política de Privacidade — Bocha Placar

Última atualização: 22 de julho de 2026

O aplicativo Bocha Placar ("nós", "aplicativo") é desenvolvido por Gabriel R. de Sousa. Esta política descreve como tratamos as informações dos usuários, em conformidade com a Lei Geral de Proteção de Dados (Lei nº 13.709/2018 — LGPD) e o Regulamento Geral de Proteção de Dados europeu (GDPR).

1. Dados que coletamos

Dados armazenados apenas no seu dispositivo (não enviados a servidores):

  • Nome e foto de perfil configurados no app;
  • Cadastro de atletas (nome, classe funcional, clube);
  • Histórico de partidas e súmulas.

Esses dados nunca saem do seu aparelho, exceto quando você mesmo compartilha uma súmula (PDF) por sua escolha.

Permissões utilizadas:

  • Câmera: usada exclusivamente para a função de medição visual (círculo de referência). Nenhuma imagem é gravada ou transmitida.

2. Dados que NÃO coletamos

  • Não coletamos localização;
  • Não coletamos contatos, mensagens ou arquivos;
  • Não vendemos dados a terceiros;
  • Não exigimos cadastro para uso do aplicativo.

3. Compras e assinaturas

As transações da versão Full são processadas integralmente pelo Google Play (Google Play Billing). Não temos acesso aos seus dados de pagamento.

4. Crianças

O aplicativo é adequado para todas as idades e não coleta intencionalmente dados de menores.

5. Exclusão de dados

Todos os dados locais podem ser removidos desinstalando o aplicativo ou usando a opção de limpeza nas configurações do app.

6. Alterações nesta política

Alterações serão publicadas nesta página com nova data de atualização.
